# 作業時間タイマー

Work Timer はチケット単位で作業時間を計測し、Redmine 標準の作業時間記録フォームから登録する機能です。タイマー列は既定で非表示です。

## タイマーを使う

1. 列設定で **Work Timer** 列を表示します。この表示列は Redmine のクエリ列には追加されません。
2. Redmine で `log_time` が許可されたチケットでタイマーを開始します。
3. 5、10、15、30、60 分の目標を選びます。
4. 必要に応じて自動停止を有効にします。自動停止が無効なら目標時間後も計測を続け、有効なら目標時刻ちょうどで停止します。
5. 停止すると作業時間が登録待ちになります。Redmine 標準の作業時間記録フォームで登録します。

## 記録と保留状態

### 作業時間を登録する

キャンセルや入力検証エラーが起きた場合、保留中タイマーは保持されます。複数タブ間でタイマー状態は同期されます。同じ Redmine インスタンスとユーザーでは、実行中または記録保留中のタイマーは 1 つだけです。

計測時間は秒単位の表示と `hh:mm` 表示があります。記録時間はタイムスタンプ区間の合計から算出され、小数第 2 位に丸められます。短時間の計測ではフォームに `0.00` が入る場合があり、最終的な受け付けは Redmine の検証に従います。

### 送信結果が不明な場合

タイマー起点のフォームを編集中または送信中は、別タブから再開・延長・破棄・記録できません。所有タブが閉じて予約が残った場合は、別タブから明示的に回復できます。送信中の状態を回復した場合、Redmine 側の結果は不明なままです。保存結果を確認できない場合も、Redmine の作業時間一覧を確認してから記録済み／未登録を確定してください。
