# ベースライン

ベースラインは、保存時点のチケットの日程を現在の日程と比較するためのスナップショットです。スケジュール計算やクリティカルパス計算には使用されません。

::: warning 開発版で追加（v0.18.0 には未収録）
開発版 HEAD では、**ベースライン保存** メニューからプロジェクトの保存済みベースラインを削除できます。確認ダイアログには保存日時、保存者、保存範囲が表示されます。削除には `manage_canvas_gantt_baseline` が必要です。Canvas Gantt の利用には既存の `view_canvas_gantt` 権限も必要です。確認すると、そのプロジェクトの保存済みスナップショット全体を取り消し不能な形で削除します。フィルタ結果から保存したベースラインでも、現在のフィルタによって削除範囲は限定されません。チケットと現在の日程は変更されません。別のユーザーがスナップショットを置き換えていた場合、古い ID による削除は拒否され、最新のベースラインを再取得します。要求の結果を確認できない場合も状態を再取得し、自動で削除を再送しません。
:::

## 保存

<a id="注意"></a>

1. 対象プロジェクトの Canvas Gantt を開きます。
2. ツールバーの **ベースライン保存** メニューで **現在のフィルタ結果を保存** または **project 全体を保存**（プロジェクト全体の保存）を選びます。
3. 内容を確認して保存します。保存すると既存のベースラインが置き換わるため、必要な記録は保存前に残してください。

各プロジェクトに保存できるベースラインは 1 つです。プロジェクト全体を保存しても、比較表示は現在チャートに表示されているチケットに限られます。

## 現在の日程と比較する

ツールバーの **ベースライン保存** メニューで **ベースライン比較を表示** をオンにすると、チケットの現在のタスクバーに保存時点の日程が重ねて表示されます。チケットにカーソルを合わせるか選択すると比較ポップオーバーが開き、開始日・期日・期間について現在値、ベースライン値、差分を確認できます。差分は暦日数です。開始日・期日の正の差分は保存時点より後の日付、期間の正の差分は期間が長くなったことを示します。

## 権限と保存先

- ベースラインを表示するには `view_canvas_gantt` が必要です。
- 保存・置換には `manage_canvas_gantt_baseline` が必要です。
- 保存先や設定の管理方法は[管理者向け設定ガイド](/ja/administration/settings)を参照してください。
- アンインストール時のデータ削除については[インストールと削除](/ja/guide/installation)を参照してください。
