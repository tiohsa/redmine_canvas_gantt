# ベースライン

ベースラインは、保存時点のスケジュールを後から比較するためのスナップショットです。スケジュール計算やクリティカルパス計算には使用されません。

## 保存

1. 対象プロジェクトの Canvas Gantt を開きます。
2. ツールバーから、現在のフィルター表示だけを保存するか、プロジェクト全体を保存するか選びます。
3. 確認して保存します。新しいスナップショットはそのプロジェクトの既存ベースラインを置き換えます。

各プロジェクトに保存できるベースラインは 1 つです。全体を保存した場合も、比較バーや差分ポップオーバーが描画されるのは現在チャートに表示されている Issue だけです。

## 権限と保存先

- ベースラインを表示するには `view_canvas_gantt` が必要です。
- 保存・置換には `manage_canvas_gantt_baseline` が必要です。
- スナップショットは Redmine の `Setting.plugin_redmine_canvas_gantt` に保存され、DB マイグレーションや別テーブルは追加されません。
- プラグインディレクトリを削除するだけでは保存データは消えません。アンインストール前に指定の cleanup task を実行すると、プラグイン設定とベースラインが削除されます。

### 注意

新しいベースラインを保存すると以前のスナップショットは置き換わります。必要な場合は、保存前に組織の運用手順に沿って記録を残してください。
