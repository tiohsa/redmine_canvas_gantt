# 親子関係と子チケットの一括登録 {#親子関係と子-issue-の一括登録}

親子関係は Redmine のチケット階層です。サイドバーで行を移動したり、Redmine の子チケット作成フォームから複数の子を登録したりできます。

## 親子関係を変更する

1. サイドバーで子にするチケットの行をドラッグします。
2. 親にするチケットの行へドロップします。
3. 親子の表示が更新されたことを確認します。

親から外すには、サイドバーのチケット行を右クリックして **親を解除** を選択します。自分自身や自分の子孫を親にするなど、無効な階層変更は拒否されます。更新には対象チケットの Redmine 標準権限が必要です。

## 子チケットをまとめて作成する {#子-issue-をまとめて作成する}

1. サイドバーまたはタスクバー上で親チケットを右クリックします。
2. **子チケットを追加** を選ぶと、Redmine の新規子チケットフォームが開きます。
3. フォーム下部の **一括チケット登録** を展開します。既定はテキスト入力です。1 行につき 1 つの件名を入力します。
4. トラッカーをまとめて指定する場合はテキスト入力上部のトラッカーメニューを選びます。**テーブル入力** に切り替えると行ごとに件名とトラッカーを選べます。行を追加・削除できます。
5. **作成** を押します。空の行は送信対象になりません。

作成されるチケットは親のプロジェクト、トラッカー、ステータス、優先度、担当者を引き継ぎます。表でトラッカーを指定した場合は、そのプロジェクトで使用可能なトラッカーに限られます。作成数の UI 上限は設定されていません。作成権限や Redmine の検証エラーで一件でも失敗すると、サーバー側で一括作成をロールバックします。エラーを修正して再実行してください。

## 注意点

一括登録は件名とトラッカーの入力を対象にし、期日など他の項目を行ごとに指定する機能ではありません。作成後の値は Redmine のチケット編集画面で変更できます。親チケットの可視性と `add_issues` / `manage_subtasks` 権限も適用されます。
