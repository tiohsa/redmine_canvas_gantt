# ワークロード

ワークロードペインは、表示中の期間についてチケットの予定工数と記録済み作業時間を比べます。予定と実績は分けて表示され、日別バーも積み上げ表示ではありません。

## ペインを開く

1. ツールバーの **工数** ボタン（ツールチップは「ワークロード」）をクリックします。
2. メニューで **ワークロードパネルを表示** にチェックを入れます。
3. 必要なら **負荷しきい値 (時間/日)** を調整し、**末端チケットのみ**、**完了チケットを含める**、**今日以降のみ** を切り替えます。これらのフォーカス条件は予定と実績の両方に適用されます。

## 読み方

- **予定** は担当者に割り当てられたチケットの見積時間を、そのチケットの稼働日に配分した値です。
- **実績** は Redmine の作業時間を、記録した作業者へ集計した値です。その作業者に予定時間がない場合も実績が表示されます。
- ピークと合計のセルでは予定と実績を別々に確認します。日別の輪郭バーと塗りつぶしバーは同じ容量基準を使います。
- 系列をクリックすると、その値に寄与したチケットを順に確認できます。凡例、ツールチップ、アクセシブルテキストも予定と実績を区別します。

フォーカス条件は個人用ブラウザー状態で、共有 URL には含まれません。

## データとアクセス制御

実績は現在の利用者が閲覧できるチケットと作業時間のみから集計されます。Redmine の `Issue#spent_hours` と値が異なる場合があります。期間の要求は両端を含め最大 730 暦日で、収集上限を超える場合は部分集計を返さずエラーになります。

作業時間の保存後は実績が更新されます。実績の読み込み中または取得失敗は `—` と表示され、予定データは引き続き利用できます。

詳細な可視性・集計上限は管理者に確認してください。
