# フィルタと保存済みクエリ

フィルターを使うと、必要な Issue に絞ってチャートを読みやすくできます。共有可能な条件は URL や Redmine の保存済みクエリに保持できます。ブラウザー内だけの条件もあるため、共有時は違いを確認してください。

## Canvas Gantt のフィルター

件名テキスト、プロジェクト、トラッカー、対象バージョン、担当者、ステータスで絞り込めます。担当者は未割当、対象バージョンはバージョンなしも選べます。条件はツールバーの検索欄または対応するフィルターメニューから指定します。

件名テキストとワークロードのフォーカス条件は個人用のブラウザー状態で、共有 URL や保存済みクエリには含まれません。

## Redmine 保存済みクエリ

Canvas Gantt は Redmine の Issue 一覧を利用して保存済みクエリを作成・編集します。ツールバーから現在のクエリを iframe または別タブで開き、対応する条件を保ったまま Canvas Gantt に戻れます。

URL の `query_id` は閲覧可能な保存済みクエリを基底条件として読み込みます。明示した Canvas または Redmine URL フィルターが、同じ項目のクエリ条件を上書きします。

## グループ化

Canvas Gantt でグループ化できる項目はプロジェクトと担当者です。対象バージョンのヘッダーは表示切り替えで、3つ目のグループ化モードではありません。グループ見出しから展開・折りたたみます。

## 共有状態と個人状態

| 状態 | 共有方法 |
| --- | --- |
| ステータス、担当者、プロジェクト、トラッカー、対象バージョン、サブプロジェクト表示 | 保存済みクエリまたは URL |
| `query_id`、グループ化、ソート、表示列 | 保存済みクエリまたは URL |
| 件名テキスト、ワークロードのフォーカス | 個人用ブラウザー状態 |
| ズーム、表示位置、行高、サイドバー幅など | ブラウザー表示設定 |

「全プロジェクトで共有」は同じブラウザープロファイルで使う設定という意味です。Redmine の他のユーザーや別ブラウザーには共有されません。同じプロファイルを使う人にはその設定が見えます。URL の完全な仕様は [URL とクエリパラメータ](/ja/features/query-parameters) を参照してください。
