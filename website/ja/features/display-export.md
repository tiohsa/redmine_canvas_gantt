# 表示設定とエクスポート

## 表示を調整する

ツールバーや表示設定では、ズーム、月・週・日表示、行高、フォントサイズ、サイドバー幅、表示列と順序を調整できます。列境界をドラッグして幅を変更でき、全画面表示も使えます。

進捗ライン、タスク名、タスクバーの日付、階層線、日付のみのタスク点、バージョンヘッダー、ベースライン、依存関係に基づく並べ替えも切り替えられます。

**手動スケジュール** では、**稼働日に合わせる** または **カレンダー日へ自由に配置** を選べます。休日にも手動で配置したい場合は後者を使います。依存関係の制約は引き続き適用されます。

**標準**・**一覧を最大化**・**チャートを最大化** で、左右ペインの表示を切り替えます。

**計算・パフォーマンス** の **クリティカルパスを計算する** は既定で有効です。オフにするとクリティカルパスと余裕日数の計算・通知を停止します。依存関係による自動スケジュールは引き続き使えます。

表示設定は Redmine ユーザー情報ではなく、ブラウザーの `localStorage` に保存されます。プロジェクト単位または同じブラウザープロファイル内の全プロジェクトに適用できます。「全プロジェクト」は Redmine の全利用者への共有を意味しません。同じプロファイルを使う人は設定を共有します。

ブラウザーのサイトデータを削除すると、保存した表示設定も失われます。

トラッカーアイコンマップでは、チケット名の横に表示するアイコンをトラッカー ID ごとに設定できます。値は `todo`、`defect`、`ticket`、`document`、`milestone`、`link` です。例: `{"1":"defect","2":"todo"}`。

進捗ラインを表示・非表示にするには、ツールバーの **進捗ライン** ボタンをクリックします。この線は今日の位置から始まり、各チケットの進捗率に応じたタスクバー上の点を行順につなぎます。完了済みや未着手の未来のチケットは今日の位置に点が置かれます。縦の今日線とは別の表示です。

### チケットダイアログのサイズ

ツールバーの **設定** を開き、パネル内をスクロールして **チケットダイアログ** を表示します。変更はすぐに反映されます。

| 項目 | 選択肢・動作 |
| --- | --- |
| 幅 | コンパクト（900 px）、標準（1200 px、既定）、ワイド（1500 px）。画面幅に収まるよう調整されます。 |
| 高さ | 自動（既定）、固定。固定時は画面の高さの 50〜90% を 5% 刻みで選択（既定 80%）。 |
| 画面全体に表示 | ブラウザーの画面全体を使用します。有効中は幅・高さの選択を変更できません。 |
| リセット | 幅を標準、高さを自動、固定高さを 80% に戻し、画面全体表示をオフにします。 |

チケットの表示・編集・作成、子チケットの作成、コメント編集に適用されます。作業時間記録とクエリのダイアログは対象外です。保存範囲は他の表示設定と共通です。

![チケットダイアログの幅・高さ・画面全体表示・リセットの設定。](/images/issue-dialog-settings-ja.png)

## PNG と CSV

1. タイムライン（右側のペイン）を表示します。
2. ツールバーの **エクスポート** を開き、用途に合う項目を選びます。

| 項目 | 出力内容 |
| --- | --- |
| PNG を出力 | 現在画面に表示されているチャート。 |
| 全体をPNG出力 | 画面外を含む、現在の表示対象の全行・全期間のチャート。 |
| CSV を出力 | 表示中のタスクデータ。親子関係・依存関係の列を含み、数値列は数値のまま出力します。 |

右側のペインが非表示の場合は出力できません。

CSV のテキスト値が `=`, `+`, `-`, `@`（全角を含む）、タブ、改行などの数式開始文字を含む場合、表計算ソフトでの実行リスクを抑えるためセル先頭にタブが追加されることがあります。引用符で囲まれたセル内のタブはデータの一部になり、プログラムによる取り込みに影響する可能性があります。対象の Excel / Calc の版と取り込み経路で、必要に応じて実ファイルを確認してください。すべての表計算ソフトや経路での安全を保証するものではありません。

### 全体をPNG出力

**全体をPNG出力** は、現在のズーム、行の高さ、フィルター、並べ替え、折りたたみ状態を使います。有効なベースラインやラベルも含みます。サイドバー、ワークロード、選択・ホバー表示は含みません。

画像は各辺 8192 px 以下、総画素数 16,777,216 以下に制限されます。長いラベルも画像幅に含まれるため、上限を超えたらズーム・行高を下げるか、フィルターで行数を減らしてください。

## 設定の共有とクエリ共有

表示設定とフィルター条件は別の仕組みです。Redmine クエリや URL で共有できる条件は [フィルタとクエリ](/ja/features/filters) と [URL とクエリパラメータ](/ja/features/query-parameters) を参照してください。
