# 表示設定とエクスポート

## 表示を調整する

ツールバーや表示設定では、ズーム、月・週・日表示、行高、フォントサイズ、サイドバー幅、表示列と順序を調整できます。列境界をドラッグして幅を変更でき、全画面表示も使えます。

進捗ライン、タスク名、階層線、日付のみのタスク点、バージョンヘッダー、ベースライン、依存関係に基づく並べ替えも切り替えられます。

表示設定の **計算・パフォーマンス** セクションにある **クリティカルパスを計算する** で、クリティカルパスと余裕日数の計算を切り替えます。既定で有効です。無効にすると、クリティカルパスと余裕日数の通知が解除されます。依存関係に基づく自動スケジュールは引き続き動作します。この設定は表示設定と同じ範囲で保存され、プロジェクト単位または現在のブラウザープロファイル内の全プロジェクトに適用できます。

表示設定は Redmine ユーザー情報ではなく、ブラウザーの `localStorage` に保存されます。プロジェクト単位または同じブラウザープロファイル内の全プロジェクトに適用できます。「全プロジェクト」は Redmine の全利用者への共有を意味しません。同じプロファイルを使う人は設定を共有します。

ブラウザーのサイトデータを削除すると、保存した表示設定も失われます。

表示設定にはトラッカー ID とアイコン種別を対応づける JSON 設定もあります。JSON の形式や値は画面の設定ヘルプに従い、未確認のキーを手入力しないでください。

進捗ラインを表示・非表示にするには、ツールバーの **進捗ライン** ボタンをクリックします。この線は今日の位置から始まり、各チケットの進捗率に応じたタスクバー上の点を行順につなぎます。完了済みや未着手の未来のチケットは今日の位置に点が置かれます。縦の今日線とは別の表示です。

## PNG と CSV

1. タイムライン（右側のペイン）を表示します。右ペインが非表示の場合、エクスポートは利用できません。
2. ツールバーの **エクスポート** メニューを開きます。
3. **PNG を出力** または **CSV を出力** を選びます。PNG は現在の表示を画像として出力し、CSV は表示中のタスクデータを親子関係列・依存関係列とともに出力します。数値列は数値のままです。

CSV のテキスト値が `=`, `+`, `-`, `@`（全角を含む）、タブ、改行などの数式開始文字を含む場合、表計算ソフトでの実行リスクを抑えるためセル先頭にタブが追加されることがあります。引用符で囲まれたセル内のタブはデータの一部になり、プログラムによる取り込みに影響する可能性があります。対象の Excel / Calc の版と取り込み経路で、必要に応じて実ファイルを確認してください。すべての表計算ソフトや経路での安全を保証するものではありません。

表計算ソフトで確認する場合は、件名が `=1+1`、親チケットの件名が `+1+1`、カスタムフィールド名が `＠SUM(1)`、値が `  -1+1` のテストチケットを用意します。引用符、カンマ、単独のキャリッジリターンを含む値も用意してください。CSV を出力し、危険なテキストの先頭に引用符で囲まれたセル内のタブがあり、埋め込まれた引用符が二重になっていることを確認します。対象の Excel / Calc で開き、値が文字列のままでセルや行が崩れないことを確認し、保存して再度開いて確認します。対応する取り込み経路ごとに繰り返してください。自動 serializer テストはこの表計算ソフトでの確認を行いません。出力時には先頭の空白や BOM の後も検査します。Excel が保存・再読込時に除去する可能性があるため、先頭の単一引用符は使用しません。

### 全体をPNG出力（開発中の機能）

全体PNG出力は開発中の機能で、リリース v0.18.1 には含まれていません。

エクスポートメニューから **全体をPNG出力** を選ぶと、現在のズームと行の高さを使い、画面外の行も含めて現在の表示対象の全行をPNGに出力します。横方向も画面外を含む全期間が対象です。現在のフィルター、並べ替え、折りたたみ状態を保ち、タスクとサマリー、および有効なベースラインの日付を描画します。出力対象はチャート領域のみで、サイドバーとワークロードペインは含まれません。選択、ホバー、作成途中の依存関係線も含まれません。画像サイズはモニターの表示倍率に左右されません。

表示が有効なタスク名・バージョン名・バーの日付ラベルの文字幅も含めて、画像の左右の範囲を確保します。長い名前は省略や縮小をせず、画像の幅を広げて出力します。

出力できる画像は、幅・高さそれぞれ 8192 ピクセル以下かつ合計 16,777,216 ピクセル以下です。ヘッダーとラベルの文字幅もこの上限に含まれます。上限を超えた場合は出力を中止します。ズームまたは行の高さを下げるか、表示行をフィルターして再度出力してください。

## 設定の共有とクエリ共有

表示設定とフィルター条件は別の仕組みです。Redmine クエリや URL で共有できる条件は [フィルタとクエリ](/ja/features/filters) と [URL とクエリパラメータ](/ja/features/query-parameters) を参照してください。
