# 基本操作

画面内ラベルは Redmine の言語やプラグイン版により異なることがあります。ここでは v0.18.0 の操作を説明します。

## 画面構成

![Redmine 7.0.0.stable 上の Canvas Gantt 0.18.0 の英語 UI。架空の Issue と依存関係を表示した日表示の画面。](/images/canvas-gantt-overview-en.png)

2026-10-11 に Redmine 7.0.0.stable と Canvas Gantt 0.18.0 で撮影した英語 UI の実画面です。架空のデモ Issue を使っています。[画像を拡大](/images/canvas-gantt-overview-en.png)

左側のサイドバーには Issue の行と表示列、右側のタイムラインには期間を示すタスクバーと依存関係が表示されます。上部のツールバーからフィルターや表示粒度、保存方式などを操作します。

## Issue の選択と移動

1. サイドバーの行、またはタイムラインのタスクバーをクリックして Issue を選択します。
2. タイムライン上でホイールやトラックパッドを操作して表示範囲を移動します。横方向のスクロールバーも利用できます。
3. 月・週・日の表示を切り替え、今日ボタンで現在日付付近へ移動します。
4. ズームはツールバー、または Ctrl / Cmd を押しながらのマウスホイールで調整します。

画面上の列や操作位置はビルドによって変わる可能性があるため、初回はヘルプダイアログも確認してください。

## 日付と期間の変更

- タスクバー本体をドラッグすると開始日と期日をまとめて移動します。
- タスクバーの左右端をドラッグすると片側の期間を調整します。
- 日付変更は対象 Issue のプロジェクトカレンダーと Redmine の権限・検証に従います。非稼働日が選択された場合、開始日は次の稼働日、期日は直前の稼働日に補正されることがあります。

日付は一括で原子的に保存されます。競合がある場合は一括更新全体がキャンセルされ、ローカルの下書きが保持されます。競合解決パネルの選択・適用手順はダイアログに従ってください。

## セルを編集する

1. 列メニューで編集する列を表示します。
2. 件名以外の編集可能なセルをダブルクリックします。担当者、ステータス、進捗率、開始日、期日、優先度、カテゴリ、予定工数、プロジェクト、トラッカー、対象バージョン、カスタムフィールドにはセルエディターが開きます。
3. 値を選択または入力して確定します。自動保存が有効ならサーバーへ送信され、無効なら下書きとして保持されます。

件名セルのダブルクリックはインライン編集を開始しません。件名リンクをクリックすると Issue 詳細が開き、行にカーソルを置いて鉛筆ボタンを押すと Redmine の Issue 編集画面が開きます。

利用できる編集項目は対象 Issue の可視性、Redmine 権限、ワークフローと編集メタデータに従います。項目別のオン・オフを変更するプラグイン設定画面はありません。

## 保存と未保存の変更を破棄する

1. 自動保存がオフの状態で編集すると、ツールバーに **保存** と **キャンセル** が表示されます。
2. 保留中の変更を Redmine に反映するには **保存** をクリックします。
3. 破棄するには **キャンセル** をクリックします。すべての未保存タスク変更を破棄し、サーバーの値を再読み込みします。この操作は 1 件や 1 フィールドだけの取り消しではありません。

自動保存がオンの場合、編集はすぐに送信されるため **キャンセル** は表示されません。保存済みの変更を戻すには Redmine の Issue 編集や履歴など通常の運用を使います。保存競合や失敗時は表示される競合解決フローに従ってください。手動保存・自動保存は同じ競合解決フローを使用します。

## 列、行の高さ、全画面

列メニューで表示列を切り替え、列境界をドラッグして幅を調整します。行の高さ、フォントサイズ、全画面表示はツールバーまたは表示設定から調整できます。値はブラウザーの `localStorage` に保存されます。

## よくある確認

- チャートが空: 開始日・期日を持つ Issue があるか、フィルターと表示範囲を確認します。
- 編集が反映されない: 対象 Issue の Redmine 権限と自動保存の状態を確認します。
- 期間が補正された: プロジェクトの業務カレンダーとサーバーから返った日付を確認します。

詳細は [フィルタ](/ja/features/filters)、[依存関係](/ja/features/dependencies)、[表示設定とエクスポート](/ja/features/display-export)、[権限](/ja/administration/permissions) を参照してください。
