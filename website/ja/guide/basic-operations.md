# 基本操作

Canvas Gantt は Redmine の表示言語に従います。チケットの件名やプロジェクト名など、ユーザーが入力したデータは元の文言のまま表示します。

## 画面構成

![Redmine 7.0.0.stable 上の Canvas Gantt 0.18.1 で、日本語表示のチケットと依存関係を表示した日表示の画面。](/images/canvas-gantt-overview-ja.png)

[画像を拡大](/images/canvas-gantt-overview-ja.png)

左側のサイドバーにはチケットの行と表示列、右側のタイムラインには期間を示すタスクバーと依存関係が表示されます。上部のツールバーからフィルターや表示粒度、保存方式などを操作します。

## チケットの選択と移動 {#issue-の選択と移動}

1. サイドバーの行、またはタイムラインのタスクバーをクリックしてチケットを選択します。
2. タイムライン上でホイールやトラックパッドを操作して表示範囲を移動します。横方向のスクロールバーも利用できます。
3. 月・週・日の表示を切り替え、今日ボタンで現在日付付近へ移動します。
4. ズームはツールバー、または Ctrl / Cmd を押しながらのマウスホイールで調整します。

その他の操作やショートカットは、画面内のヘルプで確認できます。

## 日付と期間の変更

- タスクバー本体をドラッグすると開始日と期日をまとめて移動します。
- タスクバーの左右端をドラッグすると片側の期間を調整します。

**手動スケジュール** が **稼働日に合わせる** の場合、非稼働日を選ぶと開始日は次の稼働日、期日は前の稼働日へ調整されることがあります。休日にも配置するには、[表示設定](/ja/features/display-export)で **カレンダー日へ自由に配置** を選びます。

::: warning 開発版
以下の複数ドラッグ操作は開発中であり、このマニュアルの対象である 0.19.0 には含まれません。Ctrl / Cmd または Shift で複数のチケット行を選択し、選択したバーをドラッグします。移動対象は現在ガントに表示されている選択行のみです。選択した親チケットは移動対象から除外されるため、移動したい子チケットを選択してください。選択した親バーをドラッグして対象チケットを移動できますが、選択していない子孫は自動的に追加されません。親のみを選択した場合は移動できません。表示中の選択に編集不可、派生日付、または日付未設定の親以外のチケットが含まれる場合は全件の移動を中止します。チケットを右クリックすると、そのチケットだけを選択してメニューを開きます。ガントまたはサイドバーの空白を右クリックすると複数選択を解除します。自動スケジュールが有効な場合、依存関係違反を新規に発生または悪化させる移動は拒否される場合があります。一括日程の保存が失敗すると、そのドラッグに属する未確定の変更を取り消します。別のチケット編集は同じトランザクションには含まれません。

開発版では、単体・複数選択とも、稼働日モードのバー移動はつかんだチケットを基準に移動量を稼働日数へ換算します。選択した全チケットに同じ稼働日数を各プロジェクトのカレンダーで適用し、稼働日期間を維持します。同じカレンダーで揃っていた日付は移動後も揃いますが、カレンダーが異なる場合は実際の日付が異なることがあります。開始日または期日だけのチケットは、設定済みの日付だけを移動します。
:::

開発版では、複数選択中のバー本体を修飾キーなしでクリックし、そのまま離すと、そのチケットだけの選択に切り替わります。選択に移動できないチケットが含まれていても、親だけを選択していても同じです。移動できない選択をドラッグした場合は、日付と複数選択を維持します。

## セルを編集する

1. 列メニューで編集する列を表示します。
2. 件名以外の編集可能なセルをダブルクリックします。担当者、ステータス、進捗率、開始日、期日、優先度、カテゴリ、予定工数、プロジェクト、トラッカー、対象バージョン、カスタムフィールドにはセルエディターが開きます。
3. 値を選択または入力して確定します。自動保存が有効ならサーバーへ送信され、無効なら下書きとして保持されます。

件名セルのダブルクリックはインライン編集を開始しません。件名リンクをクリックするとチケット詳細が開き、行にカーソルを置いて鉛筆ボタンを押すと Redmine のチケット編集画面が開きます。

利用できる編集項目は、対象チケットの Redmine 権限とワークフローにより異なります。詳しくは[権限設計](/ja/administration/permissions)を参照してください。

## 保存と未保存の変更を破棄する

1. 自動保存がオフの状態で編集すると、ツールバーに **保存** と **キャンセル** が表示されます。
2. 保留中の変更を Redmine に反映するには **保存** をクリックします。
3. 破棄するには **キャンセル** をクリックします。すべての未保存タスク変更を破棄し、サーバーの値を再読み込みします。この操作は 1 件や 1 フィールドだけの取り消しではありません。

::: info 依存関係の下書き
未保存の依存関係変更も **保存** と **キャンセル** の対象です。ツールバーではアイコンのみのボタンで表示され、**保存** のツールチップにチケットと依存関係の件数が別々に表示されます。変更の保留方法と一括保存できないケースは[依存関係](/ja/features/dependencies#手動保存)を参照してください。
:::

自動保存がオンの場合、編集はすぐに送信されるため **キャンセル** は表示されません。保存済みの変更を戻すには Redmine のチケット編集画面で値を変更します。

日付をまとめて更新する際に競合すると、その変更グループ全体は保存されず、下書きが保持されます。自動保存・手動保存ともに、[保存競合の解決手順](/ja/troubleshooting/#保存競合が発生した)に従ってください。

## 列、行の高さ、全画面

列メニューで表示列を切り替え、列境界をドラッグして幅を調整します。行の高さ、フォントサイズ、全画面表示や設定の保存範囲は[表示設定とエクスポート](/ja/features/display-export)を参照してください。

## よくある確認

- チャートが空: 開始日・期日を持つチケットがあるか、フィルターと表示範囲を確認します。
- 編集が反映されない: 対象チケットの Redmine 権限と自動保存の状態を確認します。
- 期間が補正された: プロジェクトの営業日カレンダーとサーバーから返った日付を確認します。

詳細は [フィルタ](/ja/features/filters)、[依存関係](/ja/features/dependencies)、[表示設定とエクスポート](/ja/features/display-export)、[権限](/ja/administration/permissions) を参照してください。
